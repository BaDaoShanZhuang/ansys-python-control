## 1. 算法:刚体配准稳妥升级(`ansys_control/zemax.py`)

把"节点位移 → 镜片刚体位姿"的旋转拟合从**纯小角度近似**升级为**SVD/Kabsch 严格刚体配准**,并新增**面形残差 RMS** 输出。

- 新增 `_fit_rigid_body_rotation()`:用 `numpy` 做 Kabsch 配准
  `R = V·diag(1,1,det(VUᵀ))·Uᵀ`,含**反射保护**(保证 det(R)=+1,不会得到镜像),
  旋转矩阵经对数映射(`_rotation_matrix_to_rotation_vector()`)转为旋转向量 `Rx/Ry/Rz`。
- **回退保护**:`numpy` 不可用 / 有效节点 < 3 / 数值异常时,自动退回原 `_fit_small_rotation()` 小角度解。状态分别标记 `computed_kabsch` 与 `computed_small_angle`。
- 平移仍取质心位移(节点位移均值),与旧版一致 —— 即光学**偏心(decenter)/ 离焦(despace)**。
- 新增**面形残差 RMS**:去除最佳刚体平移+旋转后各节点的剩余位移 RMS,表征非刚体面形误差。
  - 加入 `LensPoseRecord.rms_residual` 字段及 `as_dict()`;
  - 写入 `lens_pose_latest.csv` / `lens_pose_time_series.csv` 新增 `rms_residual` 列;
  - 计算日志、JSON、以及界面**位姿表新增"面形残差RMS"列**。

### 为什么这是改进

| 工况 | 旧小角度法 | 新 Kabsch 法 |
|---|---|---|
| 绕 Z 转 30°(实测) | 28.65°(误差 1.35°) | 30.000°(精确) |
| 小转角(≤1°) | 准确 | 准确(数值一致) |
| 是否保证正交旋转 | 否 | 是(反射保护) |
| 面形误差 | 文档声称输出但**未计算** | **真实计算并输出** |
